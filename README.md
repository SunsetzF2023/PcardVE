# 植物大战僵尸英雄 - 卡牌对战游戏

一个完整版的植物大战僵尸英雄风格卡牌对战游戏，使用纯文字界面，包含丰富的特殊能力和策略玩法。

## 🎮 游戏特色

- 🌻 **植物队** vs 🧟 **僵尸队** 的经典对战
- 🎴 30+种独特卡牌，包含10种特殊能力
- ⚔️ 策略性的战斗机制，基于法力值的动态出牌系统
- 🎯 简洁的文字界面，易于理解和游玩
- 🔄 完整的回合制对战系统

## 📋 游戏规则

### 基本规则
- 每位玩家有20点生命值
- 战场上有5个位置，可以放置卡牌
- 每回合获得1点法力值（最多10点）
- **根据法力值可以打出多张卡牌**，不是每回合只能出一张
- 卡牌会自动攻击对面的敌人
- 被冻结的卡牌无法攻击

### 胜利条件
- 将对方玩家生命值降至0
- 消灭对方所有卡牌且对方手牌为空

## 🎯 特殊能力详解

| 能力 | 效果说明 |
|------|----------|
| **必中** | 无视防御，直接对生命值造成伤害 |
| **疯狂** | 击杀卡牌后可以再次攻击 |
| **致命** | 对无防御卡牌一击必杀 |
| **秒杀** | 无视一切防御，一击必杀 |
| **防御** | 减少2点受到的伤害 |
| **双击** | 每回合攻击两次 |
| **冻结** | 使目标无法攻击1回合 |
| **抽卡** | 打出时抽取一张牌 |
| **弹回** | 将击败的卡牌弹回对方手牌 |
| **移动** | 可以移动到其他空位置 |
| **治疗** | 每回合治疗相邻卡牌1点 |

## 🎮 游戏操作

### 行动阶段选项
1. **查看手牌** - 显示当前可用的卡牌
2. **打出卡牌** - 选择卡牌和位置进行放置
3. **移动卡牌** - 移动有移动能力的卡牌（新增）
4. **结束回合** - 结束当前玩家回合

### 策略提示
- 合理管理法力值，平衡进攻和防守
- 利用卡牌的特殊能力制定战术
- **窝瓜**和**土豆地雷**是廉价的一击必杀卡牌
- **疯狂**能力配合高攻击卡牌可以清场
- **弹回**能力可以移除对方的强力卡牌
- 注意位置安排，治疗卡牌要放在被保护的卡牌旁边
