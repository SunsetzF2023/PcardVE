# 植物大战僵尸英雄 - 卡牌对战游戏

一个简化版的植物大战僵尸英雄风格卡牌对战游戏，使用纯文字界面。

## 游戏特色

- 🌻 **植物队** vs 🧟 **僵尸队** 的经典对战
- 🎴 丰富的卡牌系统，包含多种特殊能力
- ⚔️ 策略性的战斗机制
- 🎯 简洁的文字界面，易于理解和游玩

## 游戏规则

### 基本规则
- 每位玩家有20点生命值
- 战场上有5个位置，可以放置卡牌
- 每回合获得1点法力值（最多10点）
- 使用法力值打出卡牌
- 卡牌会自动攻击对面的敌人

### 胜利条件
- 将对方玩家生命值降至0
- 消灭对方所有卡牌且对方手牌为空

## 特殊能力说明

- **必中**：无视防御，必定命中目标
- **疯狂**：可以攻击多次（2-3次）
- **致命**：30%几率一击必杀
- **防御**：减少2点受到的伤害
- **双击**：每回合攻击两次
- **治疗**：每回合治疗相邻卡牌1点生命

## 安装和运行

### 环境要求
- Python 3.6+

### 运行游戏
```bash
python main.py
```

## 游戏操作

1. **查看手牌**：显示当前可用的卡牌
2. **打出卡牌**：选择卡牌和位置进行放置
3. **结束回合**：结束当前玩家回合

## 游戏策略提示

- 合理管理法力值，平衡进攻和防守
- 利用卡牌的特殊能力制定战术
- 注意位置安排，治疗卡牌要放在被保护的卡牌旁边
- 防御型卡牌适合放在前排保护后排输出
