# 植物大战僵尸英雄 - 卡牌对战游戏

一个完整的植物大战僵尸英雄风格卡牌对战游戏，包含局外卡组构建、卡牌图鉴和丰富的策略玩法。

## 🎮 游戏特色

- 🌻 **植物队** vs 🧟 **僵尸队** 的经典对战
- 🎴 30+种独特卡牌，包含10种特殊能力
- 🏗️ **卡组构建系统**：40张卡牌，每种0-4张
- 📚 **卡牌图鉴系统**：查看所有卡牌详情和稀有度
- 💾 **卡组保存/加载**：支持多套卡组配置
- ⚔️ 策略性的战斗机制，基于法力值的动态出牌系统
- 🎯 简洁的文字界面，易于理解和游玩
- 🔄 完整的回合制对战系统

## 🚀 快速开始

- **稀有**：双击、冻结、必中等实用能力

## 📋 游戏规则

### 基本规则
- 每位玩家有20点生命值
- 战场上有5个位置，可以放置卡牌
- 每回合获得1点法力值（最多10点）
- **根据法力值可以打出多张卡牌**
- 每回合自动抽取1张牌
- 被冻结的卡牌无法攻击

### 胜利条件
- 将对方玩家生命值降至0
- 消灭对方所有卡牌且对方手牌为空

## 🎯 特殊能力详解

| 能力 | 效果说明 |
|------|----------|
| **必中** | 无视防御，直接对生命值造成伤害 |
| **疯狂** | 击杀卡牌后可以再次攻击 |
| **致命** | 对无防御卡牌一击必杀 |
| **秒杀** | 无视一切防御，一击必杀 |
| **防御** | 减少2点受到的伤害 |
| **双击** | 每回合攻击两次 |
| **冻结** | 使目标无法攻击1回合 |
| **抽卡** | 打出时抽取一张牌 |
| **弹回** | 将击败的卡牌弹回对方手牌 |
| **移动** | 可以移动到其他空位置 |
| **治疗** | 每回合治疗相邻卡牌1点 |

## 🎮 游戏操作

### 局外操作
- **卡组构建**：添加/移除卡牌，查看可用卡牌
- **卡牌搜索**：按名称、描述、能力搜索
- **卡组管理**：保存/加载多套卡组配置

### 局内操作
1. **查看手牌** - 显示当前可用的卡牌
2. **打出卡牌** - 选择卡牌和位置进行放置
3. **移动卡牌** - 移动有移动能力的卡牌
4. **结束回合** - 结束当前玩家回合

## 🎯 策略提示

### 卡组构建策略
- **费用曲线**：合理分配低费和高费卡牌比例
- **能力搭配**：组合不同特殊能力形成配合
- **数量控制**：核心卡牌带满4张，功能卡牌适量
- **队伍平衡**：植物偏防守，僵尸偏进攻

### 对战策略
- **法力管理**：前期铺场，后期发力
- **位置安排**：治疗卡牌保护核心输出
- **时机把握**：合理使用秒杀和弹回效果
- **资源控制**：抽卡能力保持手牌优势
